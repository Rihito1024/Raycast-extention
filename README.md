# Raycast-extention

macOS 向け Raycast 拡張機能の開発リポジトリです。範囲を選択してスクリーンショットを撮り、コピー・編集できる **Capture** を開発しています。

> この README はローカルの `Capture/` 実装に基づいています。Capture のソースは現時点で Git 管理されていないため、リポジトリを clone するだけでは以下のコマンドを実行できません。セットアップには `Capture/` のソースが必要です。

## Capture でできること

- ドラッグした範囲を PNG 画像として保存し、画像データをクリップボードにコピーします。
- キャプチャ後、マウスがあるディスプレイの右上に通知カードを表示します。カードは 5 秒で消え、× ボタンでも閉じられます。
- 通知カードをクリックすると、撮影した画像を macOS の「プレビュー」で開きます。
- プレビューで編集して保存すると、クリップボードの画像も更新します。

通知はライト／ダーク表示に追従する独自のパネルです。macOS の通知センターは使用しません。

## 動作環境

- macOS
- Raycast
- Node.js と npm（ローカル開発用）
- macOS 標準の「プレビュー」、`screencapture`、`osascript`

## セットアップ

`Capture/` のソースがある環境で、次を実行します。npm のコマンドはリポジトリ直下ではなく、`Capture/` 内で実行してください。

```sh
cd Capture
npm install
npm run dev
```

開発用の拡張機能が Raycast に読み込まれます。

初回は macOS の「システム設定 > プライバシーとセキュリティ > 画面収録」で Raycast を許可してください。OS のバージョンによって設定項目の名称は異なります。

## 使い方

1. Raycast で「範囲キャプチャ」を実行します。
2. 撮影する範囲をドラッグします。`Space` でウィンドウ選択へ切り替え、`Esc` でキャンセルできます。
3. 画像がコピーされるので、そのまま貼り付けられます。
4. 編集する場合は、5 秒以内に右上の通知カードをクリックします。
5. プレビューのマークアップで編集し、`⌘S` で保存してから貼り付けます。マークアップのツールバーは `⇧⌘A` で表示できます。

Raycast の設定で「範囲キャプチャ」にホットキー（例: `⌥⇧S`）を割り当てると、すばやく起動できます。

### 保存先とクリップボードの更新

画像は次の場所に保存されます。通知を閉じても画像は残ります。

```text
~/Pictures/Raycast Capture/キャプチャ YYYY-MM-DD HH.mm.ss.png
```

編集内容の監視は、通知カードからプレビューを開いた場合に開始します。保存に合わせてクリップボードを更新し、次のいずれかで終了します。

- 別の内容をコピーしたとき
- プレビューのアプリ自体を終了したとき
- 監視開始から 30 分が経過したとき

通知が消えた後も、保存先から画像を開いて編集できます。その場合、編集した画像のコピーは手動で行ってください。

## 開発用コマンド

`Capture/` 内で実行します。

| コマンド           | 内容                                     |
| ------------------ | ---------------------------------------- |
| `npm run dev`      | Raycast に拡張機能を読み込み、開発を開始 |
| `npm run build`    | 拡張機能をビルド                         |
| `npm run lint`     | Raycast の lint チェックを実行           |
| `npm run fix-lint` | 自動修正可能な lint の指摘を修正         |

## ローカルのソース構成

```text
Capture/
├── package.json                     # 拡張機能の定義・npm スクリプト
├── src/
│   ├── capture-and-edit.ts           # 範囲キャプチャコマンド
│   └── capture.ts                    # 撮影・クリップボード操作
└── assets/
    ├── capture-notification.js       # クリック可能な通知パネル（JXA）
    ├── watch-clipboard.js            # 編集後の画像をコピーする監視処理（JXA）
    └── icon.png                     # 拡張機能のアイコン
```
